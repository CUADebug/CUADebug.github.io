Why diagnosis is hard

The visible failure is often not the first mistake.

CUA errors can hide in a tiny perception cue, an interaction mechanic, a planning decision, or a system artifact many steps before the final symptom.

Method

From failed trajectory to repairable root cause.

CUADebug couples tool-guided multimodal inspection with structured RCA, cautious memory retrieval, and debugger-guided re-rollout.

01

Inspect

Pair the before-screen, reasoning, grounded action, execution state, and after-screen.

02

Localize

Search backward for the first causal divergence, not the last visible symptom.

03

Structure

Emit root step, subtype, grounded evidence, correction, and inspected-step summaries.

04

Repair

Inject the diagnosis into re-rollout and measure both error avoidance and task success.

CUA error taxonomy

Five families. Thirty error subtypes.

The paper taxonomy separates what the agent perceived, where it acted, how it reasoned, what the system did, and whether the task was feasible.
